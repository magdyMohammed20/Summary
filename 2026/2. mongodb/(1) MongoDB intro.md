(1) MongoDB 
-----------
==> is an open-source, document-oriented NoSQL database. Unlike traditional relational databases that store data 
in tables and rows, MongoDB stores data in flexible, JSON-like documents. This makes it ideal for handling complex, 
unstructured, and rapidly evolving data.

(2) MongoDB is a non-relational NoSQL database

(3) Collection in MongoDB like table in sql databases

(4) document in MongoDB like table row in sql databases 

(5) document consist of fields and fields consist of key/value pair

(5) for mongodb not have pre-defined schema so each document can have different structure/fields not must all documents to have same fields

(6) in mongodb we can store the related data in same document this is makes querying data faster
